Task 7 Calculation of average reaction time & visualisation of speed (fps) and distance

In task 7, speed was converted from mph to ft per seconds (fps) to ensure speed and distance are using equivalent units. A variable called reaction_linear_model is used to store the results. The lm function was used to model the linear relationship between dist and the sum of speed_fps and square of speed_fps. This is because the total distance is the sum of the reaction and braking distance. The -1 forces the lm function to intercept at 0,0. This is because when speed is 0, distance is 0. The summary function was used to visualise the speed_fps coefficient. The reaction_time variable was created to store the coefficient of speed_fps.

#Convert speed from to ft per second.
cars$speed_fps <- cars$speed * 1.467

#Fit linear model between 
reaction_linear_model <- lm(dist ~ speed_fps + I(speed_fps^2) -1, data = cars)

#Print the summary results
summary(reaction_linear_model)

Task 13 Generate a standard distance matrix (SDM) to see the clustering of count data

In task 13, the dist function was used to transpose the rlog transformed data to get sample-to sample distances which was stored in the variable sample_dist. The as.matrix function was use to convert sample_dist into a matrix, which was stored in the variable sdm. The row names in the sdm variable use the condition in rld, whilst there were no column names. The colorRampPalette function created a custom blue colour palette consisting of 9 shades, which is based off a spectrum of 255 shades. This was assigned to the variable colours. The pheatmap function generates a heatmap using data from sdm, the distance between rows and columns uses the pre-calculated data from sample_dist and the custom colour palettes is used.

# Calculate SDM from rlog transformed data
sample_dist <- dist(t(assay(rld)))

# Get SDM in matrix form
sdm <- as.matrix(sample_dist)

# Addition of row names for a clear plot
rownames(sdm) <- rld$condition
colnames(sdm) <- NULL

# Addition of colours
colours <- colorRampPalette(rev(brewer.pal(9, "Blues")))(255)

# Generate heatmap
pheatmap(sdm, clustering_distance_rows = sample_dist, clustering_distance_cols = sample_dist, col = colours)
